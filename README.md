# Add2NumWeb

## Mô tả
Ứng dụng Web cộng 2 số lớn dùng Spring Boot + Thymeleaf + Bootstrap 5.

## Yêu cầu
- Java 17+
- Maven 3.6+

## Cách chạy
1. Clone project về
2. Chạy: mvn spring-boot:run
3. Mở trình duyệt: http://localhost:8080

## Cách clone
git clone https://github.com/rosicky838/Add2NumWeb.git

cd Add2NumWeb
